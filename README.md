# 桌面管家

一个基于 **Electron + React + TypeScript** 的 Windows 桌面管理工具：把杂乱的桌面收拾整齐，
让待办主动提醒你，工作笔记与 AI 总结一站式完成。

采用「覆盖接管式」方案——把一层透明无边框窗口挂在桌面最底层，隐藏系统原生图标后，
用「围栏 / Fence」重新组织桌面，并叠加壁纸与小组件美化。

> 原生能力（隐藏桌面图标、设置壁纸、取文件图标）通过 `koffi` 调用 Windows API，
> 因此**仅完整支持 Windows**。

## 功能

### 桌面整理

- **原位分组**（默认）：一键整理只按分类把图标收进围栏，**不移动、不改名任何文件**
- **归属目录**：归类规则可配置「关键字 → 目录」映射，一键整理时把命中的桌面项真正移动到目标目录
  - 一条规则可配多组映射，规则内按顺序取第一条命中；跨盘符（C: → D:）也可移动
  - 目录不存在自动创建，同名自动去重为 `文件 (2)`
  - 移动记录写入 `桌面\整理\.target-manifest.json`，「还原文件」按记录原路移回
- **整理新文件**：已分组状态下可增量整理新出现的文件，不影响之前已移动的内容
- 围栏可拖拽 / 折叠 / 重命名 / 删除；文件项双击打开、右键定位
- 托盘与桌面控件可「隐藏 / 显示系统桌面图标」

### 待办与提醒

- 桌面便签随手记待办，每行可设提醒（日期 + 时间，或每天 / 工作日 / 自选星期重复）
- 一条待办提醒即一个带 `todoId` 的闹铃，复用同一套响铃链路：全屏红晕 + 提醒卡片 + Windows 通知
- 响应联动：改文字同步标题、标记完成或删除自动撤掉提醒、响铃时点「已完成」一步完成
- 一次性提醒响过当天标记「已提醒」，隔天自动收起

### 归墨笔记（内置）

- 多笔记本 + 标签 + 模板新建，Markdown 编辑与导出
- 待办跟踪：进行中 / 未开始 / 已完成 + 截止日期，桌面便签「详情」直达
- AI 写作助手：接入 DeepSeek、硅基流动等国产模型，汇总素材生成周报 / 月报 / 季度总结 / 年度总结
- 图片识别文字、语音录音转写后自动贴回笔记
- **办公内网模式**：无外网时走自建内网 AI 工作台（地址在设置里填写，代码不预置内网域名），由 Electron 专用窗口
  自动完成「粘贴 → 发送 → 等回复 → 取文本」，失败自动降级为手动接力（详见下节）

### 桌面美化

- 内置壁纸（风景 / 搞笑正能量），支持放入自定义图片，定时或随机自动切换
- 桌面组件：时钟（含闹铃）、日历、便签待办，均可拖拽、显隐
- 主题换肤：深色 / 浅色 / 午夜 / 森林四套预设，强调色、面板不透明度、毛玻璃模糊可调

### 系统集成

- 开机自启、开机自动整理、开机隐藏系统图标（独立开关）
- 全局本地查找 `Ctrl + Shift + F`
- 系统托盘菜单：一键整理 / 换壁纸 / 显示隐藏图标 / 设置 / 退出

## 办公网 AI 的实现方式

内网工作台**没有可调用 API**，只有网页界面，因此走「真人操作路径的自动化」：

1. 主进程开一个专用窗口（`persist:office` 分区持久登录态，无 preload、`sandbox`、禁止 `window.open` 外出）
2. 内容进入：图片 `nativeImage` → `clipboard.writeImage()` → `webContents.paste()`（真实系统粘贴）；
   长文本同理走剪贴板；图片指令用 `execCommand('insertText')` 补充
3. 触发发送：按选择器或「发送 / send / 提交」文字探测按钮，兜底回车
4. 读取回复：选择器模式取新增片段，否则整页 `innerText` 差分（公共前缀 + 去回声 + 去掉按钮文案），
   每 2 秒采样、连续两次一致且长度达标才算生成完成
5. 站点差异抽成适配器存 `ai-config.json`（`inputSel / sendSel / responseSel / imagePrompt / resultTimeoutMs / resultMinChars`），
   改版只需改配置，不用重新打包
6. 加载失败四路收口（`did-finish-load` / `did-fail-load` / 25s 超时 / 窗口关闭），
   排除 `chrome-error://` 误判，错误码映射为中文提示并提供重试

新增办公网技能只需在渲染层注册表加一个「prep + apply」项（`image` / `text` / `file` 三种 prep），
不需要改主进程。

## 运行

```bash
npm install            # 安装依赖
npm run dev            # 开发模式（热重载）
npm run build          # 同步笔记资源 + 编译 main/preload/renderer 到 out/
npm run dist           # 打包 Windows 安装包与绿色版（输出 dist/）
npm test               # 单元测试（node --test）
npm run typecheck      # tsc --noEmit
```

打包前需先退出正在运行的桌面管家，否则 `win-unpacked` 里的文件被占用会报 `Access is denied`。

## 目录结构

```
src/
  shared/        公共类型、默认配置、分类规则、提醒计算（纯函数，可单测）
  main/          主进程：窗口、托盘、原生层(koffi)、整理引擎、壁纸、笔记数据、办公网自动化、IPC
  preload/       按窗口拆分的 API 白名单
  renderer/      React UI：围栏、桌面组件、设置面板、响铃浮层
notes-src/       归墨笔记前端源码（index.html + assets/），构建时同步到 resources/notes-app
resources/       图标、内置壁纸、同步后的笔记资源
scripts/         笔记同步、图标生成、壁纸转换等脚本
tests/           单元测试（分类规则、路径校验、标题生成、提醒逻辑、Markdown）
docs/            随包分发的文档（工具介绍）
```

## 设计取舍

- **默认不动文件**：一键整理为「原位分组」，只有配置了归属目录的关键字命中项才会真正移动，且可一键还原
- **跨盘移动**：`renameSync` 遇 `EXDEV` 时改用「复制 + 删除」，复制失败会回滚，避免留下副本；目录复制为手写递归（本机 Node 的 `fs.cpSync` 复制含中文目录名时段错误）
- **桌面接管**：`setIgnoreMouseEvents(forward)`，隐藏系统图标时完全可交互；显示系统图标时空区域点击穿透
- **安全边界**：办公网窗口不注入 preload、`nodeIntegration: false`、`sandbox: true`，对外只开白名单 IPC

## 已知限制

- 仅 Windows（依赖 Win32 API）
- 办公网首次使用需人工登录一次；文件上传依赖站点是否接受合成 paste 事件，不支持时降级手动
- 站点大改版可能需要更新适配器选择器
- 刻意不做后台静默批量抓取，一次任务一个窗口、一个动作
