# 桌面管家 · 工具介绍

一款面向 Windows 的桌面整理与效率小工具：把杂乱的桌面收拾整齐，待办主动提醒你，工作笔记、AI 总结一站式完成。

## 它能做什么

**1. 桌面一键整理（不动你的文件）**

- 点一下「一键整理」，桌面图标按「系统 / 应用程序 / 文件夹 / 文件」自动分组收纳，文件仍在原位置，不移动、不改名
- 桌面上新堆了东西？点「整理新文件」增量归组，已移走的文件不受影响
- 想恢复原状？「还原文件」一键放回

**2. 归类规则 · 自动归位**

- 在设置里给任意分类配置「关键字 → 归属目录」映射（可配多组）
- 一键整理时，文件名命中关键字的文件自动移动到对应目录，例如：
  - `报销, 凭证` → `D:\工作\报销单据`
  - `发票` → `D:\工作\发票`
- 支持跨盘符移动、同名自动去重，所有移动都能通过「还原文件」撤销

**3. 待办便签 × 闹铃提醒**

- 桌面便签随手记待办，点行尾 🔔 即可设置提醒（1 小时后 / 今天 18:00 / 明天 / 每天…）
- 到点全屏闪烁 + 提醒卡片 + 系统通知三路提醒，卡片上可直接点「已完成」
- 待办改文字、完成、删除，提醒自动同步，不会响过期铃

**4. 归墨笔记（内置笔记本）**

- 多笔记本管理 + 标签 + 模板新建（Ctrl+N 新建、Ctrl+Shift+N 从模板选），Markdown 编辑与导出
- 待办跟踪：进行中 / 未开始 / 已完成、截止日期，桌面便签的待办点「详情」直达这里的跟踪页
- AI 写作助手：接入 DeepSeek、硅基流动等国产模型（密钥自己配，办公电脑也能走内网）
  - 汇总笔记素材，一键生成季度 / 年度工作总结、周报、月报
  - 图片识别提取文字、语音录音转写，结果自动贴回笔记
  - 站点可切换：外网模型或自建内网 AI 工作台（地址在设置里填写），适配无外网环境

**5. 时钟与闹铃**

- 桌面时钟 + 多组闹铃，支持每天 / 工作日 / 自选星期重复，稍后 5 分钟再响

**6. 壁纸与主题**

- 内置精选壁纸（风景 / 搞笑正能量），也可放入自己的图片，支持定时自动换
- 深色 / 浅色 / 午夜 / 森林四套主题，透明度、强调色随心调

**7. 更多**

- 开机自启动、开机自动整理、隐藏系统图标，均有独立开关
- 全局本地查找（Ctrl+Shift+F），文件秒搜

## 安装与使用

- **安装版**：运行 `桌面管家-Setup-1.0.0.exe`，按提示安装
- **绿色版**：解压 `桌面管家-1.0.0-win64-绿色版.zip`，直接运行 `桌面管家.exe`，免安装
- 启动后常驻桌面：顶部工具栏默认收起，从右上角小胶囊展开；托盘图标可退出

## 小提示

- 「一键整理」默认只分组不移动文件，放心使用；配置了归属目录的规则才会真正移动，且随时可还原
- 所有设置（规则、提醒、主题）自动保存，重启不丢
